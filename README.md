# Portfolio

This is a simple portfolio landing page for Birhaneyesus Alemayehu.

## Files
- `hello.html` – main portfolio page

## Quick improvements included
- Better SEO metadata
- Improved layout and content hierarchy
- Clearer CTA and contact details
- Responsive single-page structure
- Contact form that opens a mail client for sending a message

## To customize
- Update email addresses and social links in `hello.html`
- Replace the placeholder project images with your actual work
- Add your real resume, GitHub, and portfolio links

## Deploy to GitHub Pages
This project is set up to deploy as a static site. Push to the `main` branch and enable GitHub Pages in the repository settings.

If you want to add your real portfolio content later, replace the placeholder text and images with your own work and resume details.
